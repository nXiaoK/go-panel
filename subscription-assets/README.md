# 订阅配置模板说明

本目录包含面板渲染订阅时使用的配置模板。YAML、INI 和 Shell 文件的关键配置旁保留了中文注释；`sing-box-android.json` 属于严格 JSON，语法不允许注释，因此在本文集中说明其默认行为和风险。

## `sing-box-android.json`

适用于官方 sing-box for Android 的手机 VPN/TUN 模式。它是由面板注入节点的模板骨架，不是可以直接使用的成品配置；仓库中的 `proxy` 暂以 `direct` 占位以通过格式校验，公开订阅渲染时会移除此占位。如果没有兼容节点，面板会返回错误，不会让境外流量静默回退直连。

### DNS 模块

- AAAA 查询默认返回空结果，即默认关闭 IPv6，避免 IPv6 绕过代理；需要 IPv6 时必须同时检查节点、路由和泄漏风险。
- 私有域名、`.cn` 与中国域名规则使用 Android 当前网络提供的本地 DNS，因此运营商仍能看到国内 DNS 查询。
- 其他域名默认经 `proxy` 使用 Cloudflare DoH；DoH 服务器主机名和地址由模板固定。
- 模板劫持普通 TCP/UDP 53 并拒绝 DoT 853，但无法识别所有封装在 HTTPS 中的第三方 DoH。Android“私人 DNS”和应用内安全 DNS 建议关闭。

### 路由模块

- 私有地址、局域网域名、中国域名和中国 IP 默认直连，未匹配流量默认走 `proxy`。
- 常见广告规则默认拒绝。
- 常见 STUN/TURN 默认拒绝，以降低 WebRTC 直连泄漏；这可能影响语音、视频通话和游戏 NAT 穿透，删除相关规则前应明确接受泄漏风险。
- 常见独立 DoH 服务强制走代理，避免被后续国内规则误判为直连。

### 远程规则集

模板每天通过代理更新 SagerNet 官方二进制规则集。首次启动依赖代理可用且规则下载成功；无法访问规则源时配置可能启动失败。完全离线部署应改用本地 `.srs` 文件，并同步修改规则集类型和路径。

### 节点兼容性

面板当前为 VLESS、VMess、Trojan、Shadowsocks 和 SOCKS5 生成 sing-box 出站。sing-box 不支持的 Snell/XHTTP 节点会被跳过；只剩不兼容或凭据不完整的节点时，订阅会拒绝输出。

若节点服务器使用域名，建立隧道前需要通过本地 DNS 引导解析，该查询对本地网络可见。可以使用服务器 IPv4 时优先填写 IP，因为模板默认关闭 IPv6。

## 其他模板

- `clash.yml`：Clash 订阅骨架，关键 DNS、代理组与分流规则在文件内使用中文注释说明。
- `surge.config`：Surge 订阅骨架，代理与规则由面板渲染；修改 DNS、MITM 或直连规则前应评估泄漏与证书风险。
- `vless-server.sh`：VLESS/VMess/Trojan 等服务端管理脚本，涉及防火墙、软件源和系统服务修改；只应在受控节点以 root 执行，并先审阅脚本来源和 Release 校验值。

## GitHub 下载代理

系统配置中的 `github_download_proxy` 默认留空，此时订阅服务器脚本直接访问 GitHub。中国大陆或其他无法稳定访问 GitHub 的服务器可填写可信的 HTTPS 代理前缀；代理必须支持“代理前缀 + `/` + 完整 GitHub URL”，并同时代理 `github.com`、`api.github.com` 与 `raw.githubusercontent.com`。面板生成绑定命令时会把该值安全传入脚本，脚本再将其保存在 `/etc/vless-reality/sub-panel.env`，供后续安装 Xray、sing-box、AnyTLS、ShadowTLS、acme.sh、wgcf 和脚本更新时复用。

代理能看到并替换下载的可执行文件，错误或失陷的代理可能导致节点被植入恶意程序，因此必须优先使用自建或明确可信的服务，且只允许 HTTPS。清空该配置后，新生成的绑定命令不再下发代理；已绑定服务器需要重新执行绑定命令，或由管理员审阅后从 `sub-panel.env` 删除 `SUB_PANEL_GITHUB_PROXY`。操作系统的 APT/DNF/APK 软件源不经过此配置，仍需在服务器侧选择可达且可信的发行版镜像。

## 节点上报备份与恢复

`vless-server.sh` 的新版上报流程会向面板保存服务端配置快照。升级面板后，现有 VPS 必须重新执行“订阅 → 节点上报”中的上报命令，并确认页面显示备份时间，之后才能依赖该快照完整恢复。仅有旧版客户端参数的节点不能还原原来的 Reality 私钥和证书，但仍可通过下面的旧记录恢复功能重建支持的协议；缺失密钥需要生成新的值。

### 操作步骤

1. 重装前在原 VPS 运行面板提供的新版上报命令；检查上报和备份成功提示，在页面刷新确认原地址、协议与备份时间。
2. 保留面板中的协议节点、订阅配置及绑定关系；重装系统本身不需要删除这些记录。
3. 重装后进入“订阅 → 节点上报 → 恢复已有节点”，选择原 VPS 的备份，复制恢复命令，以 root 在目标 VPS 执行。
4. 脚本下载并校验快照、安装所需协议组件、恢复配置和节点身份、启动服务，再以原身份上报。已有协议的机器默认拒绝覆盖，恢复失败的同一节点允许重试；失败提示时应先排查网络、组件安装或配置错误。
5. IP 发生变化时，刷新客户端订阅并核对 DNS、云防火墙、安全组和中转规则的目标地址。恢复协议配置不会替你修改云厂商网络设置。

### 已经重装且没有完整快照

在“订阅 → 节点上报 → 从旧上报记录恢复”选择原主机，核对每个协议的原端口和处理方式，再复制命令到重装后的空 VPS 执行。脚本菜单 `p` 也提供此入口，完整快照恢复仍使用 `r`。该流程仅使用面板保留的节点记录，不要求提前补做备份，也不会提前修改现有订阅。

| 协议 | 沿用的内容 | 重新生成或限制 |
| --- | --- | --- |
| SS（含 SS2022） | 原端口、加密方法和密码 | 字段必须完整 |
| Snell v4/v5 | 原端口、版本和 PSK | 不包含缺少独立凭据的 ShadowTLS 组合 |
| SOCKS5 | 原端口、用户名和密码 | 字段必须完整 |
| VMess TCP | 原端口和 UUID | 额外传输配置必须受支持 |
| VLESS Reality / Reality XHTTP | 原端口、UUID、SNI、short ID 和已保存的路径 | 原私钥无法从公钥反推，因此生成新的 X25519 密钥对；客户端必须刷新订阅以使用新公钥 |
| Trojan、VLESS Vision、独立 WS | 原端口、UUID／密码、SNI 和路径 | 仅原订阅已允许跳过证书验证时自动生成一年有效的自签证书；不能从旧记录可靠重建的共享端口／回落配置会跳过 |

恢复继续使用原节点身份，保留节点 ID、订阅链接、订阅绑定、手动名称、排序和停用状态。服务全部启动并通过检查后，脚本才把新连接参数上报到原节点，同时保存一份完整快照供以后恢复。仅查看恢复列表或复制命令不会更换密钥；执行恢复命令才会生成新密钥。

追加的中转副本会同步新公钥等服务端连接参数，同时保留各自的启停状态、名称和客户端校验策略。本机服务已恢复但面板同步失败时，按脚本提示手动重新上报；此时不要重新生成另一套密钥。

同一主机中的不支持项目会逐项显示原因并跳过，其原节点记录仍保留。不能按 IP 猜测节点归属：只有保留脚本来源、原协议及稳定主机标识且身份一致的上报记录才能使用此入口，中转副本不能当作原 VPS 恢复。已有完整快照的主机优先使用完整恢复，避免以部分上报信息覆盖其中保存的原私钥。

TLS 协议的证书也可能需要重新生成；恢复界面会明确说明是否支持自动生成。原配置要求校验证书时，不会为了恢复而自动关闭验证；某个中转副本单独启用了严格校验时也会保留，需要配置该客户端信任的证书，单纯刷新订阅不能建立证书信任。无法重建的外部依赖、共享端口关系或缺失凭据会明确提示；旧记录无法还原整机路由、WARP、端口跳跃和外部订阅站点。

### 快照格式及保管

快照是严格 JSON，不包含伪注释；字段说明如下，脚本与服务端校验逻辑以本节为配置文档：

| 模块 | 默认行为与关键取值 | 影响与风险 |
| --- | --- | --- |
| `version` | 当前为 `1`，不支持的版本拒绝恢复 | 防止不同格式被误当作可恢复配置 |
| `sourceHost` | 原节点的稳定 `node-…` 标识；恢复时沿用，不能根据 IP 猜测匹配 | 错选机器会让上报继续更新选中的旧节点，应核对原地址和协议 |
| `server` | 备份时的对外地址，用于选择原 VPS | 不是云厂商网络或 DNS 配置备份 |
| `database` | 脚本的协议数据库，包含端口、UUID、密码和 Reality 密钥等 | 属于敏感服务端配置，不能公开或当作客户端订阅分发 |
| `files` | 受限相对路径到文件文本的映射，只接收脚本允许的配置和证书 | 拒绝目录穿越及任意脚本、环境变量、系统服务文件；不做整机文件还原 |

每台机器只保留最新一次成功上传的非空快照，大小上限为 4 MiB；绑定、手动上报、成功启动服务和卸载部分协议后会刷新快照。全部协议卸载后的空配置不会清除上一份备份，因此应检查备份时间和协议列表。私钥、密码和证书单独保存在面板数据库中，普通订阅输出和备份列表不会包含它们；读取恢复内容必须使用有效的节点上报 API Key。该 Key 能访问节点备份，应与管理员凭据同等保管。面板数据库及其 SQLite/R2 备份也包含这些资料，必须限制访问；快照没有额外的应用层加密。

公网连接面板应使用 HTTPS，HTTP 会暴露 API Key 与服务端密钥。复制的上报和恢复命令包含 API Key，不要发送给他人或提交到代码仓库；更换 Key 后应重新生成命令，并更新已部署脚本的绑定。

恢复针对本脚本管理的协议配置。操作系统、云防火墙、外部 DNS、手动安装的软件和证书续期账户不属于快照范围；证书恢复后仍需确认有效期及续期安排。依赖 WARP 出口的配置目前会被拒绝备份和恢复，因为单独还原协议无法恢复 WARP 账户、系统客户端和隧道，不能静默改成直连。NaïveProxy 的域名仍需正确解析，Caddy 在新系统上需要重新申请证书。本机额外搭建的 Nginx 订阅站点及分享文件不在恢复范围内，面板的订阅链接和绑定继续保留。
